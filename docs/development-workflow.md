- 44 项研究/执行检查与 16 项留存检查通过，覆盖统计口径、固定矩阵、阶段调度、失败恢复及归档失败时保留容器。留存检查使用真实 tar/gzip 和模拟 Docker，未完成真实 Docker 归档体积与时间测量。
- 精简前后 96 个合成报告输出一致，仅排除生成时间与输出目录；固定种子的 300 组 usage 数据及准备、拒绝、失败、截断流、gzip 混合记录保持原计算口径。
- mini 的 native、controlled、session 三条真实 CLI 接容器回环假模型通过，各两次假调用、60 token，补丁与逐请求记录一致；不表示真实任务解题或官方评测通过。

## 独立操作者的剩余验收

先准备配置指定的实际模型端点、四 agent 镜像、DeepSWE 原 Pier / Verified 官方 harness 及模型/压缩服务。保持原数据、源码、算法与任务资源配额；缺少组件时记录具体缺项，不更换备用方法。AttnCompress 要求原 CUDA 路径；SWE-Pruner Pro 要求匹配的现有 head 与 Qwen3-Coder-Next 后端。

逐项完成四 agent、两数据集、五语言、六方法真实组件验收；覆盖成功/失败、缓存、辅助请求、本地 forward、方法触发/未触发、中断与评测恢复。每 worker 独立目录、容器和端口，共享服务按依赖串行。验收并发与论文 measurement_jobs 分开，验收耗时不进入论文时间排名。

准备过分析依赖的环境中重建合成和真实样本，检查 PDF/SVG、原口径桥接、unknown 显示及证据链接。确认逐指标完整性后才生成对应指标的完整排名；不得把无法隔离的工具耗时、缺失后端 forward 或准备费用填零。

真实 API 调用和 12,278 次正式任务运行需要明确的执行授权。本次实施没有启动它们。运行命令、恢复、离线重建和留存说明见 [使用说明](usage.md)。最终完成标准仍是独立实验人员可从保留记录重建全部实际研究结果；当前不能宣称正式研究验收完成。

## 开发规则

先读 [架构](architecture.md)，再读本文件。运行 Python 前激活 tokenAna，使用 Python 3.12.14。不改 upstream、不重复核验来源、不安装宿主依赖；Git 提交与推送限用户明确要求的范围，本次已获此授权。按职责组织差异，不新增 test/validation 文件；必要临时检查通过后清理产物。

运行产物、缓存及系统文件不进入 Git；请求、轨迹、配置、补丁与评测记录继续保留，开发验证的临时产物按用户要求清理。已结束试跑的 192 个环境归档经授权删除，约 10.66 GiB；对应留存记录标明无法再完整恢复文件系统，中断试跑快照保留。

四个未推送提交及本地目录快照中的对应输出副本已清理，源码版本与其他记录保留；Git 回收仅限已逐项确认的归档及其过时目录/提交对象，其他未分类对象受独立本地引用保护。已发布历史不改写。统计口径、留存模式、配置与价格的变更都要明确版本，旧研究报告不覆盖。
